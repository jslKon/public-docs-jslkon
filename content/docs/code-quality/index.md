Ghi chép từ các buổi học về chất lượng code trong khoá **Ronin Engineer S02**. Hai trang ở hai
phạm vi khác nhau của cùng một mục tiêu là giảm độ phức tạp.

- **[Clean Code](/documents/code-quality/clean-code)** — phạm vi nhỏ: naming, function, class,
  abstraction, luồng điều khiển, error handling, code review, chiến lược code.
- **[Codebase Structure](/documents/code-quality/codebase-structure)** — phạm vi lớn: năm
  architecture pattern, chiều phụ thuộc, cấu trúc project, DDD, và phân biệt Dependency Inversion
  với IoC và DI.
